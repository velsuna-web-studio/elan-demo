FAQ

Antes de reservar.

¿Tengo que elegir un servicio exacto?

No. La web puede orientar al cliente o enviarlo a una valoración previa cuando sea necesario.

¿Podemos usar Booksy o Treatwell?

Sí. La web puede servir de escaparate propio y mandar la reserva al sistema que el negocio ya utiliza.

¿Hay que mostrar los precios?

No. Podemos publicar precios, “desde”, rangos o únicamente explicar los servicios.

¿La web se adapta al móvil?

Sí. Este concepto está pensado mobile-first para tráfico que llega desde Google, Maps, Instagram y WhatsApp.
